# parlot-core

Shared semantic conventions and processors for Parlot instrumentation packages.

This is an internal dependency. Install [`parlot-instrumentation-livekit`](https://pypi.org/project/parlot-instrumentation-livekit/) (or `parlot[livekit]`) in agent code — do not import from here directly.

**Docs:** [parlot.ai/docs](https://parlot.ai/docs) · [GitHub](https://github.com/parlot-ai/sdk)
