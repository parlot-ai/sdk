# API Reference

The Parlot Python SDK provides OpenTelemetry-native instrumentation and session metadata helpers for multi-agent applications.

## Package architecture

The SDK is organized into modular packages:

| Package | PyPI Name | Description |
|---------|-----------|-------------|
| **Meta Package** | `parlot` | Convenient bundle installing framework adapters via extras (e.g. `pip install "parlot[livekit]"` or `pip install "parlot[langgraph]"`). |
| **LiveKit Adapter** | `parlot-instrumentation-livekit` | OpenTelemetry instrumentation, auto-hooks, room composite egress recording, and span processor for LiveKit Agents. |
| **LangGraph Adapter** | `parlot-instrumentation-langgraph` | Global callback handler and session management for LangGraph / LangChain graphs. |
| **Core Utilities** | `parlot-core` | Shared semantic conventions (OTel GenAI v1.41 + Conversation Contract + Voice), metadata helpers, escalation signals, and provider setup. |

## Common conventions

- **Shared `configure()` surface:** Common kwargs are documented once on [`configure()`](./configure.md); LiveKit and LangGraph pages cover extras only.
- **Keyword-only configuration:** All `configure()` methods use keyword-only arguments to prevent breaking changes when options evolve.
- **Top-level re-exports:** Common session helpers (`set_session_metadata`, `set_session_attribute`, `add_platform_ref`, `record_human_rep`, `human_escalation`) are re-exported directly from `parlot.instrumentation.livekit` and `parlot.instrumentation.langgraph` so you can import everything from your framework adapter.
- **Async & multi-process safe:** Instrumentation automatically handles LiveKit worker subprocessing and LangGraph asynchronous execution contexts.
