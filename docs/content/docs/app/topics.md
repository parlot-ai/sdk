# Topics

The **Topics** page (`/topics`) organizes customer inquiries into a durable taxonomy so you can see volume, outcomes, and cost by subject—not only by agent.

## Why topics matter

After sessions close, Parlot classifies what the interaction was about. Topics compound over time:

- Reused labels show recurring demand (for example, billing disputes).
- Newly minted topics surface emerging issues before you hard-code a taxonomy.

Use topics to prioritize product fixes, staffing, and evaluation coverage.

## Working with topic groups

On Topics you can:

- Browse topic and subtopic volume for the organization
- Merge or manage groups when labels should be combined (as the UI allows)
- Drill into filtered [Sessions](/app/sessions) for a topic

Per-agent topic detail also appears in the [agent workspace](/app/agents) Topics tab, where the catalog is scoped to one deployment.
