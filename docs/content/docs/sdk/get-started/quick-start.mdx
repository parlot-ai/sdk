# Quick Start

See what every call costs and whether it worked. Parlot’s MIT `parlotize()` instruments
production voice AI agents on [LiveKit Agents](https://docs.livekit.io/agents/),
[Pipecat](https://docs.pipecat.ai/), and [LangGraph](https://langchain-ai.github.io/langgraph/)
/ LangChain — and models each call as turns: timeline, multi-agent graph, and goal completion
with an evidence trail to the proving turns and audio.

This walkthrough uses LiveKit (Cloud, self-hosted, or
[LiveKit on Telnyx](https://telnyx.com/products/livekit-on-telnyx)). For Pipecat or LangGraph,
use the matching tab below, then the framework guides under [Next](#next).

## Install

```bash
# Using pip
pip install parlot-instrumentation-livekit

# Or using uv
uv add parlot-instrumentation-livekit

# Or via the parlot meta-package
pip install "parlot[livekit]"
# also: "parlot[pipecat]" · "parlot[langgraph]" · "parlot[all]"
```

## Instrument

Highlighted lines are what you add. Call `parlotize("…")` before constructing the session,
then follow the framework’s connect / start order.

<Tabs items={['LiveKit', 'Pipecat', 'LangGraph']}>
  <Tab value="LiveKit">

Call `parlotize("…")` before constructing `AgentSession`, then `await ctx.connect()` before
`session.start()`:

```python
from livekit.agents import AgentSession, JobContext
from parlot.instrumentation.livekit import parlotize  # [!code ++]

parlotize("my-agent")  # [!code ++]


async def entrypoint(ctx: JobContext):
    await ctx.connect()  # [!code ++]

    session = AgentSession(...)
    await session.start(agent=..., room=ctx.room)
```

  </Tab>
  <Tab value="Pipecat">

Call `parlotize("…")` once at process start, then build the pipeline with aggregators and
optional recording:

```python
from pipecat.audio.vad.silero import SileroVADAnalyzer
from pipecat.pipeline.pipeline import Pipeline
from pipecat.pipeline.worker import PipelineParams, PipelineWorker
from pipecat.processors.aggregators.llm_context import LLMContext
from pipecat.processors.aggregators.llm_response_universal import (
    LLMContextAggregatorPair,
    LLMUserAggregatorParams,
)
from parlot.instrumentation.pipecat import (  # [!code ++]
    ParlotRecordingProcessor,  # [!code ++]
    parlotize,  # [!code ++]
)  # [!code ++]

parlotize("my-pipecat-agent", version="0.1.0")  # [!code ++]

context = LLMContext(messages)
user_aggregator, assistant_aggregator = LLMContextAggregatorPair(
    context,
    user_params=LLMUserAggregatorParams(
        vad_analyzer=SileroVADAnalyzer(),
    ),
)

pipeline = Pipeline([
    transport.input(),
    stt,
    user_aggregator,
    llm,
    tts,
    transport.output(),
    ParlotRecordingProcessor(),  # [!code ++]
    assistant_aggregator,
])

worker = PipelineWorker(
    pipeline,
    params=PipelineParams(enable_metrics=True, enable_usage_metrics=True),
    enable_tracing=True,  # [!code ++]
    enable_turn_tracking=True,  # [!code ++]
)
```

  </Tab>
  <Tab value="LangGraph">

Call `parlotize("…")` once, then run the graph as usual:

```python
from parlot.instrumentation.langgraph import close_session, parlotize  # [!code ++]

parlotize("support-bot", version="0.1.0")  # [!code ++]

graph.invoke(
    {"messages": [("user", "Hello")]},
    config={"configurable": {"thread_id": "demo-1"}},
)

close_session("demo-1")  # [!code ++]
```

## Environment

```bash
export PARLOT_ENDPOINT=https://ingest.parlot.ai
export PARLOT_API_KEY=<org-scoped-key>
```

Create the API key in Parlot **Settings → API keys**. New tenants record session audio by
default (Settings → Recording allowlist `*`). Turn recording off with an empty allowlist or
`parlotize(record=False)`. On LiveKit, recording uses Room Composite egress; audio is available
when you open the session in Parlot.
