## Installation

Install the instrumentation package for your framework (or use the meta package extras):

```bash
# LiveKit Agents
uv add parlot-instrumentation-livekit
# or: uv add "parlot[livekit]"

# LangGraph / LangChain
uv add parlot-instrumentation-langgraph
# or: uv add "parlot[langgraph]"

# Pipecat
uv add parlot-instrumentation-pipecat
# or: uv add "parlot[pipecat]"

# All adapters
uv add "parlot[all]"
```

The bare `parlot` meta package pulls in `parlot-core` only. Shared helpers and `parlotize()` options live in the Interactive API pages linked above; framework guides cover adapter-specific kwargs.
