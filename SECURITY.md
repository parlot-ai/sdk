# Security Policy

## Supported Versions

We release patches for security vulnerabilities on the latest minor version of each package.

| Package | Supported |
| --- | --- |
| `parlot` | :white_check_mark: |
| `parlot-core` | :white_check_mark: |
| `parlot-instrumentation-livekit` | :white_check_mark: |
| `parlot-instrumentation-langgraph` | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in any Parlot SDK package, please do **not** open a public issue.

Instead, please send an email to **security@parlot.ai** with details about the vulnerability, reproduction steps, and potential impact.

You will receive an acknowledgment within 48 hours, followed by updates as we assess and remediate the issue.
